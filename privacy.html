Privacy Policy

Last updated: 9 November 2026

What this covers

AI101 Publish is a private tool the creator of AI 101 ภาษาคน uses to publish their own videos to their own TikTok account. Only the creator's account is connected. No other users sign in.

Data the tool receives from TikTok

  • Basic profile (scope user.info.basic): the account's open ID, display name and avatar, used only to confirm which account is connected.
  • Access and refresh tokens: issued by TikTok so the tool can upload videos on the creator's behalf.
  • Upload results (scopes video.upload, video.publish): post IDs, status and links for the creator's own videos.

How it is stored

Tokens are kept only on the creator's own computer, in a file readable by the creator's user account alone. They are never put on a server, in a code repository or in shared files. Upload results are kept in the creator's private notes about their own videos.

What is not done

The tool does not read followers, messages, comments or any other user's data. Nothing is sold, shared with third parties or used for advertising.

Deleting data and revoking access

Access can be revoked at any time in the TikTok app under Settings and privacy → Security and permissions → Apps and services. The creator can delete the stored tokens by removing the local token file.
